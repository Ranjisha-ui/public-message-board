# ADR-004: Use Modal-Based UI Interactions

**Status:** Accepted  
**Date:** 2025-01-24  

---

## Context
The UI needed to remain clean and minimal while supporting multiple interactions.

---

## Decision
All user interactions were implemented using modal dialogs.

---

## Alternatives Considered
- Multiple pages
- Inline expandable sections

---

## Consequences
- Cleaner UI and better focus
- Consistent user experience
- Requires careful state management
