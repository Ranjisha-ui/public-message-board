# ADR-001: Use Next.js App Router

**Status:** Accepted  
**Date:** 2025-01-22  

---

## Context
The project required a modern, scalable frontend framework
with built-in routing, serverless support, and production readiness.

---

## Decision
Next.js 14 App Router was chosen as the primary framework.

---

## Alternatives Considered
- React with Vite – lacks built-in serverless API support
- Pages Router – older routing model

---

## Consequences
- Cleaner routing and layout structure
- Easier integration with serverless APIs
- Requires familiarity with App Router conventions
