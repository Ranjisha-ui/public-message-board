# ADR-005: Separate UI and Logic Components

**Status:** Accepted  
**Date:** 2025-01-24  

---

## Context
Maintainability and reusability were key requirements.

---

## Decision
UI rendering and business logic were separated into different components.

---

## Alternatives Considered
- Single component handling both UI and logic

---

## Consequences
- Improved readability and testability
- Slight increase in number of files
